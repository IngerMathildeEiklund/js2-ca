# WHIMZY

WHIMZY is a social media application where the user can create a profile, add posts, comment on other posts and follow other users. 

[WHIMZY](https://whimzysocial.netlify.app/index.html)

## Features

- User authentication, (log in, register and log out)
- Create, edit and delete posts
- Following / Unfollowing other users, and the users you follow will render on the home feed
- Comment on other posts
- Viewing one users profile containing avatar image, bio and their posts
- Responsive design (mobile, tablet and desktop)


### How to use WHIMZY

Visit the site [here](https://whimzysocial.netlify.app/index.html), create an account using a "@stud.noroff.no" email and start posting!

#### Usage guidelines 

Contribute to the environment by:

- Using respectable language.
- Post friendly content.
